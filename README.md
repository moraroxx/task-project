# Task App
Простое приложение для учета задач.

## Запуск

    python task_app.py add "Купить молоко"

## Приоритеты задач

Каждая задача имеет приоритет. Допустимые значения:

'low' - низкий;
'normal' - обычный (значение по умолчанию);
'high' - высокий.

Задачи можно сортировать по приоритету: сначала 'high', затем 'normal', затем 'low'.

## Приоритеты

По умолчанию - 'normal'. Можно переопределить:

    python task_app.py add "Срочно" --priority high

Допустимые значения: 'low', 'normal', 'high'.
